# Areas

- `project` — organizing the project itself: task system, docs, GitHub issue triage
- `crash` — crashes, ASSERTs, stability hardening
- `gameplay` — game logic: characters, AI/NPCs, missions, cutscene scripting, saves
- `render` — graphics: renderer, visual bugs, effects, shadows, lighting
- `camera` — the game camera
- `input` — controls: keyboard/mouse, gamepads, DualSense, car handling feel
- `ui` — menus, options, HUD/panel text, fonts, localization, launcher screen
- `platform` — OS/driver-specific behavior, cross-platform parity, frame pacing
- `audio` — sound and music
- `devtools` — debug modes, cheats, debug keys and panels
- `architecture` — code structure, refactoring, dead code, testing infrastructure
- `release` — releases, packaging, installers, distribution, CI
- `content` — new content: editor, maps/missions, mods
