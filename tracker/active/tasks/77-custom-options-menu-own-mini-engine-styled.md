## Description
The idea — to completely replace the original options menu with a **custom** one: our own mini-engine, styled to match the game (looks built-in), more convenient and responsive than the original. **We're not doing this in 1.0** — there we went by the principle of "minimal necessary polish of the original menu". Post-1.0: consider the possibility of writing such a mini-engine. If we do — all the settings that in 1.0 were either removed from the UI (gamma, language, controls) or simplified will move there too. There would also be a place for **full control configuration via UI** (keyboard + gamepad) — what in 1.0 was either simplified or removed (see the corresponding entries). A large undertaking, not a blocker.
